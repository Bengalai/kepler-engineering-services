# Kepler Engineering Services — Animated Portfolio V3

This version is designed as a real interactive portfolio rather than embedding company-brochure pages throughout the site.

## Included
- Animated landing section and industrial control-flow visual
- Service cards with clear scope
- Industry coverage
- Project case studies with real project photos
- Click-to-open technical project details
- Technology/platform explorer for PLC, HMI, VFD, Servo and Instrumentation
- Delivery workflow from survey through support
- Client/brand network shown as text cards/pills
- Company profile PDF available as a separate button
- Responsive layout for mobile, tablet and desktop

## Run
Open `index.html` directly or deploy the folder to GitHub Pages / Vercel / Netlify.
